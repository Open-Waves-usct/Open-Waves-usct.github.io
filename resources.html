How to Access the Dataset

The OpenWaves dataset is available for download. To access the dataset, follow these steps:

  1. Download Sample Data: A 500 kHz frequency-band sample dataset is available for download directly from Huggingface. This sample dataset allows you to explore the structure and format of the data before generating the full dataset.
  2. Generate Full Dataset: Use the provided data generation software, OpenWaves.exe, to generate wavefield data for all frequencies (250 kHz to 700 kHz). The software supports customizable simulation parameters to replicate real experimental conditions.

How to Use OpenWaves.exe

The OpenWaves.exe software is a MATLAB-based tool for generating wavefield simulations from anatomical phantoms. Below is a step-by-step guide to using the software:

Step 1: Launch the Software

The Program allows you to configure the simulation parameters:

  • Data Type: Select the organ type (breast, limb, or arm).
  • Output Directory: Choose the directory where the generated data will be saved.
  • CPU Cores: Specify the number of CPU cores to use for parallel processing.
  • Simulation Frequency: Set the target frequency for the simulation (in kHz).

Step 2: Run the Simulation

Click the Start button to begin the simulation. The software will:

  1. Simulate wavefields for each source and frequency using the Convergent Born Series (CBS) algorithm.
  2. Save the generated wavefield data as .mat files incluing training data and testing data in the specified output directory.
  3. log the simulation progress to a log.txt file in the output directory. You can monitor the status of the simulation in real-time.
